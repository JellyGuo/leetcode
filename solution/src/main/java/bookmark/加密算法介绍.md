## 加密算法介绍

### 消息摘要 不可逆，固定长度输出

#### sha1加密
1.介绍SHA-1（Secure Hash Algorithm 1）是一种哈希函数，用于将数据转换为固定长度的哈希值。
2. 工作原理：SHA-1将输入数据分块处理，并通过一系列复杂的运算，生成一个160位（20字节）的哈希值作为输出。这个哈希值在理想情况下应该是唯一的，即不同的输入数据会产生不同的哈希值。
####  sha256加密
1.介绍SHA-256（Secure Hash Algorithm 256-bit）是一种安全的哈希函数，用于将任意长度的数据转换为固定长度的哈希值（通常是256位）。
加密原理：SHA-256将输入的数据分割成若干个512位的数据块，然后对每个数据块进行一系列的位操作和非线性函数运算，最终生成一个256位的哈希值作为输出结果。
####  MD5加密
1.介绍MD5（Message Digest Algorithm 5）是一种常用的哈希函数，用于将任意长度的数据转换为固定长度（通常是128位）的哈希值。
加密原理：MD5将输入的数据分割成若干个512位的数据块，然后对每个数据块进行一系列的位操作和非线性函数运算，最终生成一个128位的哈希值作为输出结果。

### 编码

#### 16进制编码
1.介绍十六进制编码（Hexadecimal Encoding）是一种将数据转换为十六进制表示的编码方式。它使用0-9和A-F这16个字符来表示数字0-15，每个字符对应4个二进制位。          2. 编码原理：十六进制编码将每个字节（8位）的二进制数据分割成两个四位的片段，然后将这些四位片段映射到一个包含16个字符的字符集中。最终生成的编码结果由这些字符组成。          需要注意的是，十六进制编码主要用于表示和处理二进制数据，它不提供加密功能。在计算机领域中，常常使用十六进制编码来表示字节序列、内存地址等。
#### base64
1.介绍Base64是一种编码方式，用于将二进制数据转换为可打印的ASCII字符。它常被用于在网络传输中传递二进制数据或存储二进制数据到文本文件中，因为ASCII字符可以在各种系统和应用程序中安全地传输和处理。          需要注意的是，Base64编码只是一种编码方式，它并不提供加密功能。它主要用于将二进制数据转换为文本形式，以便在各种应用程序中进行传输和处理。

### 加密
#### Aes加密
1.介绍AES（Advanced Encryption Standard）是一种对称加密算法，也被称为Rijndael算法。它是目前应用最广泛的对称加密算法之一。AES使用相同的密钥对数据进行加密和解密。发送方和接收方必须共享相同的密钥才能正确地进行加解密操作。
#### 3DES加密
1.介绍3DES（Triple Data Encryption Standard）是一种对称加密算法，它使用了三次DES算法对数据进行加密。
工作原理：3DES使用了三个不同的密钥对数据进行三次加密。具体过程为：先使用密钥K1对数据进行加密，然后使用密钥K2对加密后的结果进行解密，最后再使用密钥K3对解密后的结果进行加密。这样可以增加加密的强度和安全性。

#### RSA，RSA2加密
1.介绍RSA（Rivest-Shamir-Adleman）是一种非对称加密算法，常用于数据加密和数字签名。RSA使用了一对密钥，包括公钥和私钥。公钥用于加密数据，私钥用于解密数据。这种加密方式被称为非对称加密，因为加密和解密使用的是不同的密钥。

#### encodeURI加密
1.介绍encodeURI是JavaScript中的一个函数，用于对URL进行编码。它可以将URL中的特殊字符转换为%xx的形式，其中xx表示字符的ASCII码值的十六进制表示。
encodeURI函数主要用于对URL中的非字母数字字符进行编码，包括保留字符（如冒号、斜杠、问号等）和特殊字符（如空格、井号、百分号等）。编码后的URL可以在网络传输或存储时避免出现错误。
